# Hi, I'm Omar El Arab 👋

I build games and software. My current project:

### 🎮 [RA2 Engine](https://github.com/omarelarab/ra2-engine)

An unofficial, open-source engine for **Command & Conquer: Red Alert 2 — Yuri's
Revenge** on **Windows and Android**. Play the original campaigns, skirmish
against the AI, and LAN or online multiplayer with up to 8 players, using the
game files from your own copy.

- Written from scratch in C++17 with SDL2
- Behaviour calibrated against the original game
- Touch controls for phones, plus mouse and keyboard on PC

⭐ If you like it, star the repo, try it, and report bugs in the
[issues](https://github.com/omarelarab/ra2-engine/issues).
